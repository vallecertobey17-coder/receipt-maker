Bulk Receipt Maker

Receipt size 9 × 6.38 cm · up to 9 receipts per A4 sheet (landscape, 3 × 3)

🔒 Generator only: the student list is read inside this browser tab and is never saved or uploaded. Closing or refreshing the page erases it. Only the field positions and template picture are remembered.

1Upload the receipt template

A picture (PNG/JPG) or PDF of the blank receipt. It will be stretched to exactly 9 × 6.38 cm. Skip this if you print on pre-printed receipt paper.

No template yet

2Upload the student list

Excel (.xlsx) with one row per student. Make the column titles bold (e.g. Name, Student No., Receipt No., Org Fee). The bold row is read as the titles, and every column under it becomes a field you can place on the receipt. Rows above the titles (like the organization name) are ignored. From Google Sheets: File → Download → Microsoft Excel (.xlsx). CSV and .xls files work too, but they don't keep bold formatting, so their first row is used as the titles.

No list yet

3Place the fields on the template

Each column title is a field. Drag each box to where its text belongs, and drag its right edge to set the width. Text that is too long shrinks to fit. Untick columns you don't need on the receipt. Use + Add field to put the same column twice (e.g. amount in numbers and in words), or to add text that's the same on every receipt (e.g. the date).

Selected box: arrow keys nudge 0.5 mm (Shift = 2 mm).
