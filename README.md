# Bulk Receipt Maker

Generates organization-fee receipts (9 × 6.38 cm) in bulk, 9 per A4 sheet.

Open the page and follow the three steps:

1. **Students:** drop in the lists of names per section (Word .docx or PDF), or an Excel file with **bold** column titles.
2. **Details:** check the OR No. (year, semester, start number), amount, date and "payment for". The I-CONNECT Official Receipt template is built in.
3. **Save:** click **Save as PDF** to download an A4 PDF (or print directly), then confirm the batch so the next one continues the OR numbers. Print the PDF at 100% scale.

Receipt numbers are generated as `YEAR-SEMESTER-NUMBER` (e.g. `2026-1-0001`).

**Privacy:** student data is read only inside the browser tab. It is never uploaded or saved. Only the layout, template picture and receipt counter are remembered by the browser.
