# Bulk Receipt Maker

Generates organization-fee receipts (9 × 6.38 cm) in bulk, 9 per A4 sheet.

1. The I-CONNECT Official Receipt template is built in (another can be uploaded).
2. Attach the Word documents of names per section (.docx), or an .xlsx with **bold** column titles.
3. Drag each column's field onto the template.
4. Generate, print at 100% with no margins.

Receipt numbers are generated as `YEAR-SEMESTER-NUMBER` (e.g. `2026-1-0001`).

**Privacy:** student data is read only inside the browser tab. It is never uploaded or saved. Only the layout, template picture and receipt counter are remembered by the browser.
